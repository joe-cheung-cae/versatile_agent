# Subagent task contract

Use exactly these five sections for every delegated task. The packet is dynamic: replace placeholders with the actual files, interfaces, commands, evidence, constraints, and verification checks.

## 1. Objective

State the concrete outcome and the user-visible acceptance condition.

## 2. Ownership

Name the writer, owned files, and any disjoint parallel work. One writer owns overlapping files.

## 3. Inputs/evidence

List the relevant files, interfaces, commands, prior state, and evidence. Distinguish requested, observed, and effective facts.

## 4. Constraints/requirements

Record scope, safety boundaries, routing rules, non-goals, and required behavior. Do not infer missing evidence.

## 5. Verification/handoff

Name deterministic tests, review and handoff artifacts, residual gaps, and the acceptance owner.
